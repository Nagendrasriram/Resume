# 📄 Nagendra's Resume Website

Welcome to **Nagendra's Resume Website** – a sleek, responsive webpage showcasing a professional resume with core personal information, skills, and contact details. Designed for easy reading and quick navigation. 🚀

## 🌟 Project Overview

This project provides a minimalist, responsive design for a personal resume webpage using:
- **HTML** for structure
- **CSS** for styling and responsiveness

### ✨ Key Features
- 📱 **Responsive Layout**: Adapts seamlessly to various screen sizes.
- 📝 **Personal Details**: Name, contact info, and a brief about section.
- 💻 **Skill Section**: Lists core competencies in web and software development.
- 📍 **Location**: Displays address in an easy-to-read format.

## 🛠️ Technologies Used
- **HTML**: Semantic structure for each section.
- **CSS**: Styled with custom colors, font sizes, and responsive design.

## 📂 File Structure
- **index.html**: HTML file containing all sections (Personal Details, About, Skills, and Address).
- **style.css**: CSS file providing styling, animations, and layout adjustments.

## 💻 Usage
1. Clone this repository: `git clone https://github.com/yourusername/resume-website.git`
2. Open `index.html` in a browser to view the resume page.
